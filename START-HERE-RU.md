# MATERIK — инструкция для Claude, Kimi или другого coding-агента

Это полный исходный код текущего сайта-портфолио MATERIK. Архив подготовлен для редактирования сторонним агентом.

## Важно перед работой

- Не публиковать сайт и не менять доступ без прямого разрешения владельца.
- Не выполнять визуальные правки вслепую. До изменения сохранить скриншот, после изменения проверить desktop и mobile.
- Не добавлять новые секции, тексты, клиентов, цифры, награды, результаты или факты без указания владельца.
- Не генерировать новые обложки. Использовать материалы из `public/media`.
- Делать точечные изменения и показывать владельцу diff или скриншот до публикации.

## Структура

- `components/PortfolioSite.tsx` — проекты, шапка, hero, карточки, модальное окно и остальные секции.
- `app/globals.css` — все стили и адаптивность.
- `app/page.tsx` — главная страница.
- `app/portfolio/page.tsx` — отдельная страница портфолио.
- `public/media/covers` — обложки.
- `public/media/originals` — исходные изображения и видео проектов.
- `public/media/materik-wordmark.png` — фирменная надпись для шапки.

## Текущая проблемная зона

В `app/globals.css` накопилось несколько последовательных блоков переопределений шапки и hero. Не добавляйте ещё один слой поверх них. При следующей правке лучше аккуратно объединить только правила `.site-header`, `.header-inner`, `.brand`, `.hero*` и их media queries, не меняя стили остальных секций.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска открыть адрес, который покажет терминал. Перед передачей результата проверить минимум две ширины: desktop около 1440 px и телефон около 390 px.

## Сборка

```bash
npm run build
```

Проект сохранён в текущей Vinext-структуре ChatGPT Sites. Для переноса на другой хостинг может потребоваться отдельная адаптация конфигурации. Сначала исправляйте дизайн и функциональность в этой версии, а перенос выполняйте отдельной задачей.

## Содержимое hero

В hero должны использоваться только:

1. «Самурайский компас» — `/media/covers/compass.webp`.
